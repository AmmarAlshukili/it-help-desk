# IT Help Desk Ticket Management System

A web-based IT Help Desk application built with Python, Flask, and SQLite to manage IT support requests.

## Features

- User login and authentication
- Create and manage support tickets
- Search and filter tickets
- Update ticket status and priority
- Assign tickets to IT technicians
- Ticket comments and history
- Dashboard for ticket statistics
- SQLite database for data storage

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Git and GitHub

## Local Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/AmmarAlshukili/it-help-desk.git
   cd it-help-desk
   ```

2. Create and activate a virtual environment:

   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure the required environment variables, including a secure Flask secret key.

5. Initialize the database and create an administrator account using the project's setup scripts.

6. Start the application using the appropriate Flask command configured in the project.
